# Dokumentation der Module

Jede Datei belegt, nach welchen offiziellen Unterlagen ein Modul gebaut ist. Sie nennt die Quellen,
ordnet jede Vorgabe der Umsetzung zu und führt Auslegungen und Grenzen auf.

Aufbau jeder Datei:

1. **Quellen:** Dokumente mit Stand. Die Kürzel (Q1, Q2 …) werden in den Tabellen verwendet.
2. **Vorgaben und Umsetzung:** Offizielle Regel, Fundstelle, Umsetzung im Code.
3. **Auslegungen:** Stellen, an denen die Quellen nicht eindeutig sind.
4. **Eigene Ergänzungen:** Was nicht aus den Quellen stammt, etwa Gartenbilder oder Vorschläge.

Kriterientexte sind in der App gekürzt. Maßgeblich bleiben die Originaldokumente.
